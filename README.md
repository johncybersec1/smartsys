# Smart School System

Smart School is an educational platform designed to facilitate seamless interaction between students and teachers. This web application is an ongoing personal project aimed at enhancing online learning experiences while also serving as a medium for improving my understanding of web security and development.

### Overview

Smart School provides a digital environment where students can access educational resources, submit assignments, and communicate with their teachers. Likewise, teachers can create courses, manage student progress, and interact with their students effectively. This project has helped me deepen my knowledge of web development, security best practices, and new technologies.

### Features

* User Authentication & Authorization: Secure login and role-based access for students and teachers.

* Course Management: Teachers can create and manage courses, upload resources, and grade assignments.

* Student Dashboard: Students can enroll in courses, access study materials, and track their progress.

* Assignment Submission & Evaluation: A streamlined system for students to submit assignments and receive feedback.

* Real-time Messaging: In-app communication between students and teachers.

* Admin Panel: Management of users, courses, and system-wide settings.

* Secure Access: Implemented best practices for authentication and data security.

### Technologies Used

* Backend: Flask (Python)

* Frontend: HTML, CSS, JavaScript
  
* Database: MySQL Workbench

* Authentication: Flask-Login, JWT-based authentication

* Security: CSRF protection, input validation, and encryption techniques

* Hosting: Deployed on a cloud platform (Render)

### Learning Outcomes

Working on Smart School has significantly enhanced my technical skills in:

* Flask and Python web development

* Implementing secure authentication and authorization

* Managing databases and designing RESTful APIs

* Enhancing application security by preventing vulnerabilities

* Deploying and maintaining a full-fledged web application
